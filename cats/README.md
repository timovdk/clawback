# Cats

Every image in this folder can show up after sending a complaint.

1. Drop a `.gif` (or `.webp`, `.png`, `.jpg`) in here.
2. If it needs credit (e.g. a Creative Commons licence), add it to `credits.json`.
3. Run `npm run cats` to update `cats.json`.

The starter gifs are from Wikimedia Commons; their creators and licences are in `credits.json`
and are shown under each gif in the app.
